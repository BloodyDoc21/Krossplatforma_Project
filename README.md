# Трекер расходов

Приложение на C++17 и Qt 6. Окно трекера принимает расходы и показывает список, число записей и итог. История хранится в `history.txt` в рабочем каталоге приложения.

## Сборка и запуск

Откройте `ExpenseTracker.pro` в Qt Creator, выберите настольный набор Qt 6, выполните **Run qmake** и соберите проект. Для сборки из терминала создайте отдельный каталог сборки, выполните `qmake ../ExpenseTracker.pro` и запустите `mingw32-make` (MinGW) или `make` (Linux/macOS). Запустите собранный `ExpenseTracker`.

## Консоль

Для запуска консольного режима передайте аргумент `--console`.

| Команда | Действие |
| --- | --- |
| `add 120,50 Обед` | Записать расход |
| `list` | Показать расходы |
| `total` | Показать общую сумму |
| `exit` | Завершить работу |

Поддерживаются точка и запятая в сумме. Ошибки ввода передаются сигналом `errorOccurred`. Сигнал `expenseAdded` подключён к выводу записи и обновлению итога.

## Дерево объектов

- **Удалить сводку** ставит панель в очередь удаления через `deleteLater()`. Панель уничтожает свои дочерние метки.
- **Переместить итог** меняет родителя и компоновщик метки. После перемещения в окно она переживает удаление сводки.
- **Демо setParent(nullptr)** отвязывает временную метку. Панель удаляет оставшуюся метку, а отвязанная получает собственный вызов `deleteLater()`.
- В выводе приложения видны события [CREATE], [DESTROY], [SET_PARENT] и [DELETE_LATER].

## Просмотр расходов

- **Старт / Стоп** запускает и останавливает таймер. **Медленнее / Быстрее** меняют интервал от 200 до 5000 мс.
- **Режим** переподключает обработчик таймера. «Цикл» выбирает следующую запись, «Случайно» выбирает случайную, «Мигание» включает и выключает подсветку.
- Левый щелчок по списку выбирает следующую запись, правый — предыдущую. Клавиши со стрелками работают как обычно.
- **+ Быстрый выбор** создаёт кнопку текущей записи. **Очистить кнопки** удаляет кнопки быстрого выбора, сохраняя записи.
- **Сменить обработчик выбора** направляет сигнал списка в заголовок окна или в строку состояния. В выводе приложения видны [TIMER], [MOUSE], [DYNAMIC] и [LIST].

## Адаптивная форма

- **Добавить** сохраняет сумму, название, категорию и описание. Описание сохранённого расхода видно в подсказке строки. **Отмена** очищает поля формы.
- Название и категория растут в ширину. Сумма по умолчанию занимает только свою рекомендуемую ширину, а описание растёт в ширину и высоту.
- **Растягивать сумму** и **Растягивать описание** меняют политики во время работы. **Компактно / Свободно** меняют поля окна и зазоры формы.
- **Дамп политик** показывает горизонтальную и вертикальную политики, а **Дамп размеров** выводит текущий, рекомендуемый и минимальный размеры.

Смотрите журнал в **Application Output** Qt Creator. При запуске из терминала Windows можно установить переменную `QT_FORCE_STDERR_LOGGING=1`.
